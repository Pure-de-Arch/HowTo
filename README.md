# HowTo
Telepíts egy ArchLi nucot natívan vagy virtuálsi gépben.
Frissítsd a csomagkezeélőt: pacman -Syu
Telepítsd az archiso csomagot: pacman -S archiso
 A pur De Arch szervezetben keresd meg a számodra szinpatikus repositorit. AMikor megjelenik egy új kiadés pl GNOME, akkor érdemes új iso-t készíteni.
 git clone megfeleéő repo neve 
 pl. git clone 
 lápj be a letöltött könyvtárba: ccd könyvtárnév
 pl: cd 
 futtasd a 30-instal--- parancsot
